## 2. E0.5: fix the decoder (bilinear model)

**Question**: does sharing parameters across output genes let the model predict genes that never responded in training?

- **H**: a bilinear model Δ_kj = μ_j + g_jᵀ W p_k beats both the MLP and ridge from E0.4. Here g_j is the output gene's embedding, p_k the perturbation embedding, and W is d × d. The test uses the same 5 worlds, the same folds and the same metrics. Pre-registered thresholds:
  - median Δr against the E0.4 ridge ≥ 0.1 (p < 0.01)
  - gap closure ≥ 0.2
  - in ≥ 4 of 5 worlds
- **Why**: E0.4 showed that the per-gene head is the ceiling. This is the Ahlmann-Eltze linear baseline ([study guide](./study-guide.md)).
- **Build**:
  - `models.BilinearDelta`: closed-form ridge on vec(W) via a Kronecker product, or a torch version with the same masking.
  - Use g = p = the co-expression embedding, d ∈ {16, 64}, with d chosen on validation.
  - Script `scripts/run_e0_5.py`: copy `run_e0_4.py`, keep the pilot gate (positive control: oracle embedding + bilinear) and the guard, and change only the models dictionary.
- **Expected learning**: in a linear-Gaussian world, W ≈ −κI turns co-expression directly into a predicted effect. If it still fails, the bottleneck is the representation, not the decoder.

## 3. E0.6: directed knowledge vs co-expression

**Question**: do directed priors (like GO, STRING or CollecTRI) fix the regulator-vs-null confusion?

- **H**: `grn_prior` embeddings raise the null-knockout AUROC from about 0.5 to ≥ 0.75, and they beat co-expression on Systema r. The prior is noisy: 60% edge recall plus an equal number of false edges. Test both a signed and an unsigned version.
- **Build**: `embeddings.grn_prior_embedding(toy.W, recall, false_rate, signed, dim, seed)`. Sweep recall over {0.2, 0.4, 0.6, 0.8} as an exploratory analysis. This gives a "how good must my prior be?" curve.
- **Teaches**: causal direction, P(Y | do(X)), and why GEARS uses knowledge graphs.

## 5. Real data (after E0.5 and E0.6)

**E0.7: the Replogle 2022 K562 essential pseudobulk.**
- Source: `K562_essential_normalized_bulk_01.h5ad`, 80 MB, figshare article 20029387.
- Add a `data.from_pseudobulk(adata)` loader, with `anndata` as an optional dependency.
- There are no control single cells, so use the *response-PCA* embedding: gene loadings from the PCA of the training Δ, computed per fold to avoid leakage.
- There is no oracle, so use a split-half replicate of cells as the ceiling where single cells are available. Otherwise report gap closure against MeanShift only.
- Expect much lower scores. The goal is to see whether the E0.5 and E0.6 ranking of models holds on real data.
