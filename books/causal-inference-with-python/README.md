# Causal Inference with Python

## Introduction to Causal Inference

- Association is when two quantities or random variables move together
- Causality is when change in one variable causes change in another

In an experiment, we apply a treatment (intervention) and evaluate the effect (outcome). Examples:

- On sale (price drop) -> Increase in sale
- Medicine -> Become healthier

The fundamental problem of causal inference is that you can never observe the same unit with and without treatment. Based on that, we need to have the same unit, at the same time, with and without the treatment. With that, we can compare these two counterfactual situations.
